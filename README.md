# Earthquake_Prediction
Earthquakes are natural disasters that can cause significant damage and loss of life. Accurate prediction of earthquakes is essential for developing early warning systems, disaster planning, risk assessment, and scientific research. This project aims to predict the magnitude, time and the location of Earthquake occurring in a South Asian region which majorly includes all the parts of India from the historic data of that region using various Machine learning and Deep Learning models.

# Introduction
Earthquake prediction is a critical area of research aimed at reducing the impact of seismic events. This project employs various machine learning and deep learning techniques to predict earthquake occurrences based on historical data. The primary algorithms investigated include Long Short-Term Memory (LSTM), LSTM with a shared input layer, and Artificial Neural Networks (ANN).

# Methodology
Data Preprocessing: Cleaning and preparing the dataset for model training.
Location-Based Data Clustering: Grouping earthquake occurrences based on their geographical locations.
Feature Engineering: Creating relevant features for the prediction models.
Model Training and Evaluation: Training various machine learning and deep learning models and evaluating their performance.

# Results
The LSTM model achieved significant results in predicting earthquakes, demonstrating its effectiveness. The comparative analysis showed that LSTM models, particularly those with shared input layers, outperformed traditional ANN models.
